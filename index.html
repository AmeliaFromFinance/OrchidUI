Settings windows for your Streamer.bot actions

Describe the window in your action's code. OrchidUI draws it natively on Windows, Linux and macOS, checks what people type, and saves it to a global variable.

Download Read the docs

Free and open source (MIT). Windows 10 and 11, Linux through Wine, Bottles, Lutris or Proton, and macOS on Apple Silicon.

Everything a settings window needs

Most elements take a label, a description and a key. The key is the name the value is saved under.

Every kind of setting

Switches, sliders, dropdowns, multi-selects, durations, colours, tables, file pickers, images and buttons.

Conditions and checks

ShowWhen and EnableWhen react as values change. Required and Validate turn a card red and hold off saving.

Six themes

Orchid, Amethyst, Sakura, Synthwave, Graphite and Daylight. Or set your own accent, fonts and sizes in a theme file.

Native on every desktop

Under Wine, the window is drawn by a native Linux or macOS program, so it uses your own fonts, scaling and screen reader.

Read it anywhere

Values are plain JSON in orchid_{NAME}. Read them from any action with OrchidSettings.Load, or without the DLL at all.

Keyboard and screen readers

Ctrl+S saves, Ctrl+F searches every tab, Ctrl+1 to 9 switches tabs. Every control has a name for screen readers.

Set up in a few minutes

Two downloads from the same release: the DLL your action references, and a small host program that draws the window.

  1. Download OrchidUI.dll and the host zip for your system from Releases.
  2. With Streamer.bot closed, put the DLL next to Streamer.bot.exe and unzip the host into a folder called OrchidUI beside it.
  3. Reference the DLL. In your Execute C# Code sub-action, go to References, then Add reference from file.
  4. Run your action. Streamer.bot's log says Settings window opened.

Which host zip?

Pick the one for the system you're on, even when Streamer.bot runs under Wine.

Windows 10 or 11orchid-host-win-x64.zip
Linuxorchid-host-linux-x64.zipor linux-arm64 on ARM. Wine, Bottles, Lutris and Proton. Linux guide
macOSorchid-host-osx-arm64.zipApple Silicon, with Whisky, CrossOver or Wine. macOS guide

Your first window

Paste this into an Execute C# Code sub-action and run it. Add tabs, conditions and checks as you go.

The second argument is the fallback. Lists, tables and durations have their own getters, and the docs list every element and modifier.

Themes

Dark by default, with an orchid pink accent. Pick one with SetTheme("Sakura"), or users can choose their own with ORCHIDUI_THEME.

Built to fail safely

The window runs as its own program. If it crashes, Streamer.bot logs it and carries on, and running the action again reopens it. A release DLL only starts the host files from its own release, checked by SHA-256, and every download has build provenance you can check with gh attestation verify. Passwords are masked on screen and in logs, but saved as plain text, like any global variable. OrchidUI isn't affiliated with Streamer.bot. Security policy
